# 📒 NoteBook - React Notes App

A simple and attractive **NoteBook application** built using **React.js and Vite**.

This application allows users to create, search, view, and delete notes easily through a clean and responsive user interface.

---

## 🚀 Features

- ➕ Add new notes
- 📝 Add Note Title and Description
- 🔍 Search notes
- 🗑️ Delete notes
- 📊 Display Total Notes count
- 👀 Display currently Showing notes count
- 🔄 Form automatically resets after adding a note
- 📱 Responsive and attractive UI
- ⚡ Fast development using Vite

---

## 🛠️ Technologies Used

- **React.js**
- **JavaScript**
- **HTML5**
- **CSS3**
- **Vite**
